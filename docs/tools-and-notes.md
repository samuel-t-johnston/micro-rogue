# Tools 

An list of potentially useful tools for roguelike dev, game dev, Javascript dev.
Lately expanded into a general list of interesting stuff related to roguelikes.

**Used in ROGµE**

 - Node.js - for all the JS stuff
 - Vitest and happy-dom for unit testing
 - ESLint and Prettier - code linting and formatting
 - Github Pages - for easy demo
   - https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

**Tools I Might Look Into**

(I make no claim of quality here, just a place to jot down tools I'm interested in.)

 - REXPaint - ASCII art tool
   - https://www.gridsagegames.com/rexpaint
 - aseprite - Animated sprite editor and pixel art tool. $20 on Itch.io or Steam, or compile it yourself.
   - https://www.aseprite.org/
   - https://github.com/aseprite/aseprite
 - LibreSprite - An open and free fork of aesprite
   - https://libresprite.github.io/
